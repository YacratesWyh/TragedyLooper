## [0.0.1] - 2026-01-21 (早期阶段)

早期快速原型迭代，主要里程碑：

- **核心卡牌系统**：唯一卡牌追踪、使用状态、禁止牌机制、结算引擎
- **FS-01 剧本**：新手模组完整数据
- **基础 UI 组件**：版图、角色卡、行动牌、手牌区、规则速查
- **角色系统**：32 角色立绘 Sprite Sheet、能力定义、死亡机制
- **结算系统**：移动优先 → 禁止抵消 → 指示物应用
