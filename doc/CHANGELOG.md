## [0.3.0] - 2026-03-05

  - 独立页面路由（`/poison`）

- **版本更新说明展示**
  - 应用内 changelog 弹窗（`src/changelog.ts`）

## [0.1.0] - 2026-01-24

### 新增

- **用户注册与身份系统**（`src/shared/identity.ts`）
- **回放功能**
- **WebSocket 多人联机**
  - 合并 HTTP + WS 服务器（`server/combined-server.js`）
  - 房间创建/加入、房主逻辑
  - 断线 5 分钟内自动重连

- **拖拽纠错**：行动牌可拖拽更正错误放置

### 优化

- UI 全面重整（v0.05~v0.08 多次迭代）
- 角色素材修正与更准确的角色配置
- 提示系统优化

---

## [0.0.1] - 2026-01-21 (早期阶段)

早期快速原型迭代，主要里程碑：

- **核心卡牌系统**：唯一卡牌追踪、使用状态、禁止牌机制、结算引擎
- **FS-01 剧本**：新手模组完整数据
- **基础 UI 组件**：版图、角色卡、行动牌、手牌区、规则速查
- **角色系统**：32 角色立绘 Sprite Sheet、能力定义、死亡机制
- **结算系统**：移动优先 → 禁止抵消 → 指示物应用

---

## 版本说明

- **0.x.x**: 核心功能开发中，接口不稳定
- **1.0.0**: 计划为首个可发布版本（完整游戏循环 + 稳定联机）

当前处于 **0.3.0** 阶段，已从单游戏转型为多游戏平台。
