## 角色卡特殊特性（被动）

以下角色在卡面上标注了"特性"框，这些是被动效果，不需要友好触发：

| 角色 | 被动特性 |
|------|---------|
| factor | 无法分配身份，取代一个未使用身份 |
| godly_being | 制作脚本时指定轮回数，该轮回前不登场 |
| henchman | 初始区域每轮回可由脚本家任意变更；作为犯人的事件不发生 |
| illusion | 不可放置行动牌；同区域行动牌均摊效果 |
| black_cat | 每轮回开始时在神社放置1个阴谋标记 |
| scientist | 每轮回开始时由脚本家选择放置友好/不安/阴谋标记之一 |
| ai | 不可为路人；作为犯人时所有标记视为... (待确认) |
| transfer_student | 制作脚本时指定日期，该日期前不配置（延迟登场） |
| boss | 制作脚本时指定领地区域 |
| cult_leader | 作为犯人的事件效果计算两次 |
| copycat | 无法分配身份，与另一角色共享身份 |
| sacred_tree | 主角能力阶段可将此角色标记转移至同区域角色 |
| little_sister | 不可分配友好无限身份；可借用同区域大人的友好能力 |
