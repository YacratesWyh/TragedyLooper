## 技术债务

- 联机服务器以内存保存房间，重启不保留对局；
- 状态同步仍以客户端提交整包状态为主，不是服务器权威事件模型；
- ESLint 对部分既有 effect 派生 UI 状态采用非阻断策略；
- 大体积游戏素材会显著增加镜像构建上下文和传输时间；
- 素材授权需要由部署者根据实际使用场景确认。
